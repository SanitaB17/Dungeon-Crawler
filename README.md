# 🧱 Dungeon Crawler — Learning Project Log

This repository contains my progress while following the **Dungeon Crawler Game Development Course** by _Coding With Russ_ on Udemy.  
The course teaches how to build a complete 2D dungeon crawler game from scratch using **Python** and **Pygame**.

---

## 🎯 Goal

To learn **game development fundamentals** in Python by creating a fully functional dungeon crawler — including movement, collisions, animations, AI, and level design.

---

## 🧩 About the Course

> “In this course you will learn how to use the very popular Pygame module by coding a dungeon crawler game completely from scratch.”

The course covers:

- Game loops and frame management
- Keyboard input and movement
- Drawing images and shapes
- Working with sprites and animations
- Using **Object-Oriented Programming (OOP)**
- Building tilemaps for level design
- Implementing enemy **AI**
- Collision detection
- Custom level editor integration
